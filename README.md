# Aplicación de Dos Pantallas - Jetpack Compose

Proyecto de desarrollo móvil desarrollado en Android Studio utilizando **Jetpack Compose**.

## Descripción del Proyecto
Esta aplicación implementa una interfaz de usuario moderna y reactiva basada en componentes declarativos, estructurada en dos pantallas principales para demostrar la navegación y el paso de datos entre vistas.

## Características de la Aplicación:
- **Pantalla Principal (Pantalla 1)**: Contiene un saludo inicial y un campo interactivo con un botón para procesar la acción y navegar hacia la siguiente vista.
- **Segunda Pantalla (Pantalla 2)**: Recibe y muestra la información enviada desde la primera pantalla, incluyendo un botón de retorno ("Volver").
- **Navegación**: Gestionada de forma fluida mediante los componentes nativos de Jetpack Compose.

## Tecnologías Utilizadas:
- **Lenguaje**: Kotlin
- **Framework UI**: Jetpack Compose
- **Entorno de Desarrollo**: Android Studio
